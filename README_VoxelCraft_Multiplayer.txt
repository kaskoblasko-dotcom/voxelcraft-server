VoxelCraft v2.08 multiplayer server

1. Extract this ZIP into a normal writable folder.
2. Open Command Prompt in this folder (address bar: type cmd).
3. Run: npm install
4. Run: npm start
5. Leave the server running. Open VoxelCraft_v2.08.html and connect to ws://localhost:3000 from this PC. Other PCs need the host LAN IP and firewall access; internet play needs a publicly reachable host and secure WebSocket setup.

PvP: while in the same room and dimension, aim at another player and click/hold attack. Weapon damage is sent to the target by the server. This is a prototype, not cheat-proof authoritative combat. Mob state is not yet synchronized by this version.
